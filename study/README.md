# Study folder

This folder contains the controlled ablation study for the Phonebot
caller-info pipeline, with the LaTeX paper, the figures, the aggregated
data, and the CLI tool that overrides `src/config.py` from the command
line.

## Files

| File | Role |
|---|---|
| `cli.py` | CLI override harness for `main.run()` (mutates `src.config` before importing main) |
| `analyze.py` | Aggregates every report under `results/` and `study/results/` into CSVs and figures |
| `paper.tex` / `paper.pdf` | Research paper (LaTeX source + built PDF) |
| `figures/*.png` | Plots embedded in the paper, regenerated by `analyze.py` |
| `data/*.csv` | Aggregated ablation tables (one row per run, plus per-key and mismatch detail) |
| `results/` | Reports written by ablation runs launched through `cli.py` |

## Reproducing the figures

```bash
python -m study.analyze
```

Reads every `report_*.json` under `results/` and `study/results/`, writes
the CSVs to `study/data/`, and renders every PNG to `study/figures/`.

## Reproducing the ablation runs

The CLI exposes every relevant constant in `src/config.py` as a flag.

### 1. Transcript-only baseline (no SpeechLM, no targeted re-listen)

```bash
python -m study.cli \
  --transcription elevenlabs:scribe_v2 \
  --instruct "" \
  --timestamp "" \
  --no-targeted \
  --no-auto-resume \
  --results-dir study/results \
  --tag scribe_only_no_audiollm
```

Runs the full extraction pipeline with only the Scribe transcript and the
transcript-LLM (no Voxtral, no Whisper, no Layer 4, no Layer 4.5). Uses
no GPU memory.

### 2. Voxtral-only without targeted re-listen

```bash
python -m study.cli \
  --transcription voxtral:mistralai/Voxtral-Mini-3B-2507 \
  --instruct voxtral:mistralai/Voxtral-Mini-3B-2507 \
  --timestamp "" \
  --no-targeted \
  --no-auto-resume \
  --results-dir study/results \
  --tag voxtral_only_no_targeted
```

Same as the strongest single-Voxtral pipeline minus the targeted
re-listen, to isolate the contribution of Layer 4.5.

### 3. Best-known dual-STT configuration

```bash
python -m study.cli \
  --transcription voxtral:mistralai/Voxtral-Mini-3B-2507,elevenlabs:scribe_v2 \
  --instruct voxtral:mistralai/Voxtral-Mini-3B-2507 \
  --timestamp whisper:openai/whisper-large-v3-turbo \
  --no-auto-resume \
  --results-dir study/results \
  --tag dual_full_pipeline
```

## Building the paper

```bash
cd study
pdflatex -interaction=nonstopmode paper.tex
pdflatex -interaction=nonstopmode paper.tex   # second pass for cross-refs
```

The figures referenced by the paper live in `study/figures/`; running
`python -m study.analyze` first ensures they are up to date with the
current set of reports.
